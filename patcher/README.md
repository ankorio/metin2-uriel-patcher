# patcher

The one-exe wrapper around `tools/` and `stub/`. Drop `dist/TriarchPatcher.exe`
into the game folder and run it; it derives the keystream, rebuilds the exe,
resolves every offset, deploys the stub and installs the mods. The full
specification of each step, the output files and the failure modes is in
[`docs/03-patcher-pipeline.md`](../docs/03-patcher-pipeline.md).

```
python sync.py                                  # stage tools/, mods/, the stub DLL into the package
set PYTHONPATH=src                              # or: export PYTHONPATH=src
python -m triarch_patcher <game folder> --console   # run from source
build.bat stub                                  # build the DLL with MSVC, then freeze the exe
build.bat                                       # freeze only
```

`src/triarch_patcher/vendor/` and `src/triarch_patcher/resources/` are
generated by `sync.py` and ignored by git. Edit `tools/`, `mods/` and `stub/`
instead.
